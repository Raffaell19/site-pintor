# PintorPro | Landing Page de Alta Conversão

Landing page profissional desenvolvida para serviços de pintura residencial, comercial e fachadas de alto padrão, com foco total em conversão para WhatsApp e chamadas telefônicas.

## 🚀 Tecnologias
- **HTML5 Semântico:** Estrutura otimizada para SEO e acessibilidade (ARIA labels).
- **CSS3 Moderno (Vanilla):** Design tokens, tipografia refinada (*Outfit* + *Plus Jakarta Sans*), zero dependências externas e performance 100/100.
- **JavaScript Modular Puro:** Modal de triagem rápida para WhatsApp, contador animado com *IntersectionObserver*, accordion de FAQ e menu mobile.

## 📦 Como Subir na Vercel
1. Acesse [vercel.com/new](https://vercel.com/new);
2. Conecte sua conta do GitHub e selecione o repositório `site-pintor`;
3. Mantenha as configurações padrão (Framework Preset: **Other**) e clique em **Deploy**;
4. Seu site estará no ar em segundos com SSL gratuito e CDN global!

## ⚙️ Personalização do WhatsApp
Para alterar o número do WhatsApp de destino:
Abra o arquivo `script.js` e altere a constante `WHATSAPP_PHONE` na linha 8 com o seu número (ex: `5511999999999`).
